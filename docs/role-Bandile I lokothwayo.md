Roles: Software Programmer/Tester

A Software Programmer is responsible for designing, writing, testing, and maintaining code that enables computer systems and applications to function effectively. They translate user requirements and business needs into functional software solutions by using programming languages.

In this role the programmer collaborates with other team members such as requirements analyst , system designers, and project managers to build reliable and scalable applications. They debug and troubleshoot issues, optimize performance, and ensure that software meets quality standards. 

Since there is no dedicated tester, the programmer is also responsible for the testing phase of development. This includes performing unit testing to verify that individual components or functions work as expected, as well as integration testing to ensure that different parts of the system interact correctly. Testing is conducted based on the provided requirements to confirm that the software behaves as intended and meets user expectations.

They are also expected to document their code, follow best practices, and adapt to evolving project requirements and industry trends.
